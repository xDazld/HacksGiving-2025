# Assets Directory

This directory should contain the following image files for the Expo app:

## Required Assets

### icon.png
- **Size**: 1024x1024 pixels
- **Purpose**: App icon
- **Format**: PNG with transparency

### splash.png
- **Size**: 1242x2436 pixels (or similar aspect ratio)
- **Purpose**: Splash screen shown while app loads
- **Format**: PNG

### adaptive-icon.png (Android)
- **Size**: 1024x1024 pixels
- **Purpose**: Android adaptive icon
- **Format**: PNG with transparency
- **Note**: Should work on circular, square, and rounded square masks

### favicon.png (Web)
- **Size**: 48x48 pixels (or 16x16, 32x32)
- **Purpose**: Web browser favicon
- **Format**: PNG

## Placeholder Images

For development purposes, you can create simple placeholder images:

1. Use any image editor (GIMP, Photoshop, Figma, etc.)
2. Create images with the "Thunderdomes" name or logo
3. Use Milwaukee Domes branding colors if available
4. Ensure proper dimensions for each asset

## Branding Suggestions

- Use green (#27ae60) as primary color (matches app theme)
- Include dome/greenhouse imagery
- Keep design simple and recognizable at small sizes
